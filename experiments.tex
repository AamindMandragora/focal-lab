\section{Experiments}
\label{sec:experiments}
%% ============================================================

We evaluate \Tool on two tasks spanning distinct constraint regimes: math reasoning (\GSM) and text-to-SQL (\Spider).
Synthesized strategies are evaluated on three models: \QwenSmall, \QwenCoder, and \QwenBig.
All strategies are synthesized offline using \SynthGPT with temperature 0.7 and $K=10$ synthesis iterations.
Experiments are run on multi-GPU NVIDIA servers using vLLM; our default local setup uses \texttt{CUDA\_VISIBLE\_DEVICES=1,2}. For the remote \texttt{focal} setup with \texttt{Qwen/Qwen2.5-Coder-14B-Instruct}, we use \texttt{tensor\_parallel\_size=2}, \texttt{gpu\_memory\_utilization=0.6}, \texttt{max\_model\_len=3072}, and \texttt{enforce\_eager=True}.

\paragraph{Baselines.}
We compare against unconstrained generation, \Crane~\cite{crane2025} (adaptive constrained-unconstrained switching), and \IterGen~\cite{itergen2025} (grammar-aware backtracking).

\paragraph{Tasks and metrics.}
On \GSM~\cite{gsm_symbolic2024}, LLMs generate symbolic expressions for grade-school math problems; we report functional equivalence to the ground truth (Acc.) and constrained-window syntax validity (CW), which measures whether delimited \texttt{<< >>} spans parse as valid arithmetic.
On \Spider~\cite{spider2018}, LLMs generate SQL queries from natural language and database schemas; we report execution accuracy (Ex.Acc.) against the gold database and CW for SQL syntax.
