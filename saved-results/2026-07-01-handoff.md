## What this project is (one paragraph)

"Dynamic CSD Gen" / **metaDecode**: a constrained-decoding framework where a large
author model (Sonnet-4-6 via Bedrock) synthesizes CSD *strategies* (Dafny `.dfy`
method bodies) that are compiled to Python and evaluated on three benchmarks —
**GSM** (baseline: CRANE), **Spider/SQL** (baseline: IterGen), **SMILES/chemistry**
(baseline: CARS). The active campaign goal is to WIN every Qwen3.5 cell against
those baselines on held-out sets by improving the framework (helpers, feedback
loop), then run ablations, then write the final doc. Paper deadline: 2026-05-25
(already past per memory — treat as "wrap up" mode, confirm with user).

## Gotchas learned this session
- `_ALL_HELPER_NAMES` is scraped from `TOOL_REFERENCE`, not hand-listed — edit the
  menu text, not a tuple.
- Real-returning Dafny externs must return `self._dafny.BigRational(x)` (see
  `IdToLogit`), and the Dafny form is `function {:extern} {:axiom} Name(...): real`
  (matches existing `ValidNextTokenCount(...): nat`).
- Dafny rejects identifiers beginning with `_` in strategy bodies (a compile-smoke
  hit this).
- The compiler stages the library into temp `agents/` + `proofs/` dirs — a reference
  `.dfy` used standalone needs its `include` path adjusted to just
  `VerifiedAgentSynthesis.dfy` for a manual compile test (not needed in the real
  pipeline).
- GPUs 1 & 2 on focal had leaked/held memory (0% util) — use 0 or 3.
